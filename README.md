# 🐷 小猪存钱罐 - 财商教育 RPG 游戏

> 一款专为小学生设计的财商教育网页游戏，通过 RPG 游戏化的方式，让孩子在玩中学，从认识人民币到理解储蓄、复利等金融知识。

## 🎮 游戏特色

### 🏰 RPG 式成长体验
- **玩家等级系统**：20级成长曲线，完成任务、学习知识都能升级
- **技能树**：5大财商技能（钱币识别、储蓄达人、投资小能手、聪明消费、任务专家）
- **徽章收集**：15+成就徽章，记录学习历程
- **属性系统**：智慧、储蓄、勇气、幸运四大属性

### 🗺️ 财富小镇探索
- 🏛️ **小镇广场** - 中心区域，接取主线任务
- 🏫 **钱币学堂** - 认识人民币、学习元角分换算
- 🏠 **小猪之家** - 三只小猪存钱罐，学习分配零花钱
- 📋 **任务公告板** - 打工赚钱，培养劳动意识
- 🛒 **熊老板商店** - 模拟消费，学会理性购物
- 🏦 **财富银行** - 了解储蓄、利息和复利的魔力
- 🌳 **成长之树** - 查看学习进度和成就
- 🏡 **我的家** - 休息整理，保存进度

### ⚔️ 知识问答战斗
把枯燥的知识问答变成有趣的RPG战斗！
- 答对问题 → 对敌人造成伤害
- 答错问题 → 自己受到伤害
- 击败NPC获得金币、经验和技能提升

### 👥 丰富的NPC角色
- 🐰 兔博士 - 财商导师
- 🦉 猫头鹰老师 - 钱币学堂老师
- 🐷 三只小猪 - 存钱罐精灵
- 🐻 熊大壮 - 任务管理员
- 🐼 熊老板 - 杂货店老板
- 🦊 狐小骗 - 神秘小贩（小心骗子！）
- 🐢 龟爷爷 - 银行老客户
- 🐱 山猫镇长 - 小镇镇长

## 🎯 游戏玩法指南

### 新手流程
1. **初到小镇** - 进入小镇广场，和兔博士对话接取第一个任务
2. **认识钱币** - 去钱币学堂学习人民币知识
3. **打工赚钱** - 去任务公告板完成任务赚取第一桶金
4. **分配零花钱** - 去小猪之家，把钱分配给三只小猪
5. **知识战斗** - 遇到知识事件，用学到的知识击败NPC
6. **解锁更多** - 升级、解锁银行、商店等新场景

### 小技巧
- 💡 多和NPC对话，他们会教你很多财商知识
- 💡 完成任务不仅能赚钱，还能获得经验和技能提升
- 💡 记得把钱存一部分到银行，让钱生钱（利息）
- 💡 收集所有徽章，成为财商小达人！

- ✅ 手机浏览器
- ✅ 添加到主屏幕（PWA 体验）

2. 点击分享按钮
3. 选择"添加到主屏幕"

## 💾 数据存储

游戏进度自动保存在浏览器的 localStorage 中：
- 玩家等级、经验、金币
- 已完成的任务和知识事件
- 银行存款和利息
- 存钱罐分配
- 收集的徽章

> ⚠️ 注意：清除浏览器数据会导致进度丢失
